# Proton pump inhibitors and pembrolizumab in metastatic urothelial carcinoma

R code for the analysis reported in:

> Effectiveness of pembrolizumab in patients with urothelial carcinoma receiving proton pump inhibitors. *Urologic Oncology: Seminars and Original Investigations*. <https://www.sciencedirect.com/science/article/pii/S1078143922000680>

Multicenter retrospective cohort; inverse probability of treatment weighting with Cox and logistic regression for overall survival, immune progression-free survival, and objective response.

## Contents

`script.R`: analysis.

## Requirements

R 4.x with `lubridate`, `pec`, `tidyverse`.

## Data

Patient-level data are not included in this repository.
